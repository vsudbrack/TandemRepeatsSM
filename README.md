# Supplementary Material for *The evolution of tandem repeat sequences under partial selfing and different modes of selection*

This repository contains the SLiM simulation scripts and Mathematica notebooks used in the analyses presented in:

Vitor Sudbrack and Charles Mullon. *The evolution of tandem repeat sequences under partial selfing and different modes of selection.* Heredity (2026): 1–14.

The repository includes:
- SLiM simulation code compatible with versions 4.3 and 5.0,
- Mathematica notebooks used for analytical derivations and numerical analyses.

In particular, the SLiM 5.0 implementation (`TandemRepeats_Simplified_v5.slim`) was developed as a simplified example illustrating how structural variants, specifically tandem repeat sequences, can be modelled in SLiM. This version was presented during the SLiM Workshop as a pedagogical example for simulations involving structural variation, feel free to explore.

The publication is available at www.sudbrack.me
